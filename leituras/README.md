# Leituras e Referências do GEB

Este diretório reúne materiais de leitura e referência para os estudos do grupo.

---

## Categorias

### Core
Leituras fundamentais para introdução e base conceitual.

### Avançado
Textos mais específicos, focados em neuroengenharia, processamento de sinais e reabilitação.

---

## Sugestões iniciais

- fundamentos de biomecatrônica;
- neuroengenharia aplicada;
- instrumentação biomédica;
- processamento de sinais biológicos;
- tecnologias assistivas;
- jogos sérios para reabilitação;
- reabilitação motora e robótica assistiva.

---

## Como usar este diretório

- mantenha artigos e materiais organizados por tema;
- publique resumos e anotações em arquivos próprios;
- priorize referências com relevância para os projetos em andamento do GEB.
