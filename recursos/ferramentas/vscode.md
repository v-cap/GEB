# Configurações para ambiente de desenvolvimento no VSCode
- Baixar e instalar o [Visual Studio Code](https://code.visualstudio.com/)

## Extensão ESP-IDF
- Instalar os [pré-requisitos para o ESP-IDF](https://docs.espressif.com/projects/idf-im-ui/en/latest/prerequisites.html) no seu sistema operacional.
- Clicar no ícone de extensões na barra lateral do VS Code (ou pressionar `Shift+Ctrl+X`) e pesquisar pela extensão "ESP-IDF" (Espressif Systems).
- Instalar a extensão "ESP-IDF" da Espressif Systems.
- Caso o ESP-IDF ainda não esteja instalado em seu computador:
  - Na paleta de comandos do VS Code (`Shift+Ctrl+P`), digite e execute o comando ESP-IDF: Open ESP-IDF Installation Manager. Isso abrirá o gerenciador de pacotes para a instalação do ESP-IDF no seu computador.
  - Instale o ESP-IDF no seu computador.
