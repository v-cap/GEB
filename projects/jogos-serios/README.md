# Jogos Sérios

## Visão Geral

Projeto de desenvolvimento de aplicações interativas voltadas à reabilitação e ao apoio ao desempenho do usuário.

## Objetivos

- criar aplicações interativas;
- integrar sensores e dados biomecânicos;
- apoiar reabilitação motora e cognitiva.

## Estado Atual

Em fase de prototipagem e integração com tecnologias de monitoramento.
