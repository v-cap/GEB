# Neuroestimulador

## Visão Geral

Projeto voltado ao desenvolvimento de dispositivos e protocolos para neuroestimulação, com foco em pesquisa aplicada e experimentação.

## Objetivos

- desenvolver fontes de microcorrentes;
- investigar protocolos de estimulação;
- apoiar pesquisas em neuroengenharia.

## Estado Atual

Em fase de desenvolvimento e validação funcional.
