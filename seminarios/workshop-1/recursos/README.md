# Recursos do Workshop 1

Este diretório reúne materiais complementares para o workshop inicial do GEB.

## Conteúdo sugerido

- lista de componentes e materiais necessários;
- links externos de referência técnica;
- resumo de conceitos fundamentais;
- referências de sensores e módulos utilizados.

## Checklist de materiais

- Arduino Nano / UNO / Mega ou ESP32
- MPU-9250 / GY-521
- LCD 1602A I2C
- FSR
- ADS1115
- Servo MG946R
- LM2596
- resistores 10kΩ
- protoboard e fios jumper

## Observação

Os materiais podem ser ajustados conforme disponibilidade do laboratório, objetivos do workshop e demanda do grupo.
